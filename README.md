
# Ubuntu Community Food Centre Website

## 1. Project Overview

The Ubuntu Community Food Centre website is a website developed to support a non-profit organisation that helps food-insecure families and individuals in South Africa.

The website provides information about food assistance, community support, volunteering and donations.

## 2. Project Objectives

The objectives of this website are to:

- Provide information about the organisation.
- Display the services offered by the centre.
- Allow visitors to search for services.
- Allow visitors to submit enquiries.
- Allow visitors to contact the organisation.
- Provide an interactive location map.
- Make the website accessible on desktop, tablet and mobile devices.

## 3. Target Audience

The target audience includes:

- Families and individuals experiencing food insecurity.
- People interested in volunteering.
- Individuals and businesses interested in donating.
- Community members seeking assistance.
- Potential community partners.

## 4. Technologies Used

The website was developed using:

- HTML5 – for the structure and content of the website.
- CSS3 – for styling, layout, responsiveness and animations.
- JavaScript – for interactive website features.
- Leaflet – for the interactive map.
- OpenStreetMap – for map information.
- FormSubmit – for contact form email submissions.
- Visual Studio Code – as the development environment.
- ChatGPT – for development guidance, code assistance, troubleshooting and AI-generated images.

## 5. Website Pages

The website contains five separate pages:

### 5.1 Home Page

The Home page introduces the Ubuntu Community Food Centre and displays information about the organisation. It includes a photo gallery and an interactive location map.

### 5.2 About Us Page

The About Us page explains the organisation's purpose, vision, mission and values.

### 5.3 Services Page

The Services page displays five services:

- Food Parcels
- Prepared Meals
- Community Support
- Volunteer Opportunities
- Donation Support

It also includes a search function that allows visitors to filter services.

### 5.4 Enquiries Page

The Enquiries page contains a form that allows visitors to submit requests about the organisation's services.

The form includes required-field validation and a confirmation message. It is currently a demonstration form and does not send enquiries to an email server.

### 5.5 Contact Us Page

The Contact Us page contains a contact form with fields for:

- Full Name
- Email Address
- Subject
- Message

The form uses JavaScript validation and FormSubmit AJAX integration to send messages to the configured email address.

The receiving email address must be verified with FormSubmit before email submissions can be received.

## 6. Website Features

The website includes:

- Navigation between five separate pages.
- Responsive desktop, tablet and mobile layouts.
- Service search and filtering.
- Image gallery with a lightbox.
- Interactive map using Leaflet and OpenStreetMap.
- Contact form validation.
- Contact form email submission using FormSubmit.
- Enquiry form validation.
- CSS hover effects and transitions.
- Page fade-in animation.
- Service card hover animations.
- Accessible form labels and image descriptions.
- Search engine optimisation elements.

## 7. Search Engine Optimisation (SEO)

SEO improvements include:

- Unique page titles.
- Meta descriptions.
- Relevant keywords.
- Descriptive image filenames.
- Alternative text for images.
- Internal navigation links.
- Mobile-friendly layouts.
- A robots.txt file.
- A sitemap.xml file.

The sitemap must be updated with the final deployed website address before publication.

## 8. How to Run the Website

1. Open the Ubuntu Community Food Centre project folder in Visual Studio Code.
2. Open the project using Live Server.
3. Open the Home page in a web browser.
4. Use the navigation menu to visit the other pages.
5. Test the search, gallery, map and forms.

An internet connection is required for the online map tiles and FormSubmit email service.
